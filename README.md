AI Smart Event Management Platform

AI-powered event management platform developed as part of SAP Labs Vibethon, focused on automating event scheduling, registrations, and generating smart audience insights.

Overview
This project was built during a hackathon to design a modern event management system enhanced with AI-driven features. The platform aims to simplify event coordination while providing intelligent insights for organizers.

Features
- Event creation and scheduling
- User registration workflows
- AI-assisted audience insights and recommendations
- Responsive and clean user interface
- Scalable frontend architecture

Tech Stack
- Frontend: React, TypeScript
- Styling: Tailwind CSS, shadcn/ui
- Build Tool: Vite
- Package Management: npm / bun

Project Context
This project was developed under time-bound hackathon conditions, with a focus on rapid prototyping, clean UI design, and practical system architecture.

Project Status
Frontend implementation and core workflows are complete. Backend integration and advanced AI features can be extended further.

Getting Started
1. Clone the repository  
   git clone https://github.com/rudrakshmittal19-star/Event-Management-Site.git

2. Install dependencies  
   npm install

3. Run the development server  
   npm run dev
